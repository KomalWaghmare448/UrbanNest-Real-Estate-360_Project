# UrbanNest-Real-Estate-360_Project
 UrbanNest – Real Estate 360° Analytics
 
*Project Overview
UrbanNest is an interactive real estate analytics project developed using Microsoft Power BI to analyze property sales, revenue, marketing performance, customer leads, and agent productivity.

*Tools Used
-Power BI
-DAX
-Power Query
-Microsoft Excel

*Dashboards
  ->Executive Overview
  ->Property Analytics
  ->Sales Analytics 
  ->Marketing Analytics
  ->Agent Performance Analytics

*Key Features
-Data Cleaning and Transformation
-Data Modeling and Relationships
-DAX Measures and KPI Development
-Interactive Dashboards and Slicers

*Business Performance Analysis
To transform real estate data into meaningful insights and support data-driven business decisions
